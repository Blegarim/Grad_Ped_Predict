## Current config versus historical instructions

The repository supports more than the latest experiment. Default configs still describe a three-task full visual model with frozen pretrained TinyViT, 8 motion channels, macro_f1 selection and images. The v4 study is a pixel-free pose-kinematics experiment with explicit overrides; resolved_config.yaml in each run is the experiment identity. Never infer the latest experiment from defaults alone.

- .claude/skills/behavior-preserving-port/SKILL.md still says OLD is vendored. tests/_capture/README.md correctly points to legacy-archive after cutover. Preserve fixtures; do not follow the old checkout recipe casually in a dirty tree.
- .claude/skills/experiment-tracking/SKILL.md is historical: config_resolved.yaml versus current resolved_config.yaml, motion_only versus current kinematics_only, F1-primary rule versus v4 crosses_auc selection and declared detection-budget comparison, and never-commit-CSVs versus now-tracked experiment CSVs. Its baseline-results.md is an unfilled template, not a result source.
- setup.md remains valuable for data generation and evaluation order, but its onset recipes are F1-selected pose_full runs with old baseline comparability notes. Use docs/RERUN_PLAN_2026-09-26.md and actual c4 resolved configs for v4 reproduction, not those recipes unchanged.
- configs/train.yaml default is macro_f1, despite accepting crosses_auc. configs/model.yaml keeps vit_frozen_eval=false and train_frame_proj=false for historical compatibility; these are not evidence that the current pixel-free model uses a visual backbone.
- Config comments can lag: configs/balance.yaml mentions default loss class weights, but configs/train.yaml has use_class_weights=false. Values and resolved run artifacts are the controlling evidence.
- Pose is a coupled contract: pose.enabled, 58-dimensional data/model motion, and model.motion_norm=none must agree. Standardization values are copied into resolved config. Onset uses 96-frame lookahead, four-frame bins and 32-frame reporting horizon. Censored binary labels are placeholders; supervision must use hazard censor masks, not treat them as genuine negatives.
- CI and pre-commit define ruff plus non-slow pytest; this read-only history analysis did not rerun training or tests. The tests themselves have left rows in the research index, so filter test_* rows when counting experiments.
